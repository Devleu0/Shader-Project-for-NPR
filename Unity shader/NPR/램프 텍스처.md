# 1. 툰 셰이딩과 램프 텍스처

> 코드: [README 의 전체 코드](./README.md#전체-코드) 중 `NPRToonPass.hlsl` 의 `ToonFrag` 앞부분

## 목표
빛의 세기(0~1)를 부드러운 그라데이션 대신 **계단 모양 색**으로 바꿉니다.

## 원리
일반 Lambert 는 `saturate(dot(N, L))` 을 그대로 밝기로 씁니다. 툰 셰이딩은 이 값을 **램프(Ramp) 텍스처의 가로 좌표(U)** 로 사용해 색을 *조회*합니다. 램프가 3칸짜리 계단이면 결과도 3단계가 됩니다.

```hlsl
half NdotL = dot(normalWS, lightDir) * 0.5h + 0.5h;   // [-1,1] → [0,1] (하프 램버트)
half3 ramp = SAMPLE_TEXTURE2D(_WarmRamp, sampler_point_clamp, half2(NdotL, 0.5h)).rgb;
half3 color = _Color.rgb * ramp * mainLight.color;
```

- `*0.5+0.5` : 빛 반대편(음수)도 램프의 왼쪽 끝으로 매핑하려는 처리입니다. 그림자 쪽이 완전히 검게 죽지 않습니다.
- `sampler_point_clamp` : 이름 자체가 Unity 의 **인라인 샘플러** 규칙입니다. 텍스처 임포트 설정(Wrap/Filter)과 상관없이 Point + Clamp 로 읽으므로 계단 경계가 번지지 않습니다.
- v 좌표를 `0.5` 로 고정하는 이유: 램프는 가로 방향 1차원 정보뿐입니다.

## 램프 텍스처
램프 제작법은 [README 의 4번 단계](./README.md#따라-하기)를 보세요. 256×16 이미지에 왼쪽→오른쪽으로 어두운 색→밝은 색을 칸(어두움/중간/밝음 3칸)으로 채웁니다.
여러 칸 수의 램프를 만들어 바꿔 끼우며 결과를 비교해 보세요.

## 실습
1. 머티리얼의 Warm Ramp 슬롯에 직접 만든 램프를 넣고 Directional Light 를 회전시킵니다.
2. 램프를 2칸/5칸으로 직접 만들어 교체해 봅니다.
3. `* 0.5 + 0.5` 를 지우고(`saturate(dot)`), 어두운 면이 어떻게 달라지는지 비교합니다.

## 그림자
`GetMainLight(shadowCoord)` 의 `shadowAttenuation` 으로 그림자 안인지 판단하고, 그림자 안에서는 램프의 **가장 어두운 칸**을 씁니다. 단순히 곱하면 색이 탁해져 만화 느낌이 사라집니다. (Light 의 Shadow Type 을 Soft/Hard 로 설정해야 합니다.)
