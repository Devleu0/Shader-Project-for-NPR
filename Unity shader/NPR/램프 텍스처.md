# 툰 셰이딩과 램프 텍스처**

가장 기본적인 카툰 렌더링(툰 셰이딩 또는 셀 셰이딩)의 핵심 원리를 이해하고 구현합니다. 우리는 빛의 명암을 부드러운 그라데이션이 아닌, 명확하게 구분되는 단계로 표현하여 만화 같은 느낌을 만들 것입니다.

## **램프 텍스처 (Ramp Texture)**

일반적인 3D 렌더링에서 빛의 양은 표면과 빛의 각도에 따라 0(어두움)부터 1(밝음)까지 부드러운 값으로 계산됩니다. 툰 셰이딩에서는 이 0\~1 사이의 값을 그대로 사용하는 대신, '램프 텍스처'라고 불리는 작은 1D 텍스처를 읽는 '좌표'로 사용합니다.  

예를 들어, 빛의 양이 0.8로 계산되었다면, 램프 텍스처의 80% 지점에 있는 색상을 가져와 픽셀에 칠합니다. 램프 텍스처가 두 가지 색상(어두운 색, 밝은 색)으로만 이루어져 있다면, 모든 픽셀은 둘 중 하나의 색으로만 칠해져 뚜렷한 명암 경계를 만들게 됩니다.

---

#  URP Toon Shader (Ramp Texture 기반 셀 셰이딩)

이 문서는 Unity **Universal Render Pipeline (URP)** 환경에서 램프 텍스처를 사용한 **Toon 셰이딩**을 구현하는 방법을 설명합니다. 기존 Surface Shader 튜토리얼을 **URP HLSL 기반 셰이더**로 변환한 버전입니다.

---

## 셰이더 파일 생성

**Project 창** →
`Create > Shader > Empty Shader` 를 선택하고, 파일 이름을 `NPRCelShader.shader` 로 지정합니다.

---

## Property 정의

Material Inspector에서 사용할 프로퍼티들을 정의합니다.

```hlsl
Properties
{
    _Color ("기본 색상", Color) = (1,1,1,1)
    _RampTex ("램프 텍스처", 2D) = "white" {}
}
```

* **_Color** : 기본 색상(알베도)
* **_RampTex** : 조명 단계를 제어할 램프 텍스처

---

## 3. URP 셰이더 전체 코드

```hlsl
Shader "URP/NPRCelShader"
{
    Properties
    {
        _Color ("기본 색상", Color) = (1,1,1,1)
        _RampTex ("램프 텍스처", 2D) = "white" {}
    }

    SubShader
    {
        Tags { "RenderType"="Opaque" "RenderPipeline"="UniversalRenderPipeline" }

        Pass
        {
            Name "ForwardLit"
            Tags { "LightMode"="UniversalForward" }

            HLSLPROGRAM
            #pragma vertex vert
            #pragma fragment frag

            // URP 핵심 라이브러리
            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Lighting.hlsl"

            // Material Properties
            CBUFFER_START(UnityPerMaterial)
                float4 _Color;
            CBUFFER_END

            TEXTURE2D(_RampTex);
            SAMPLER(sampler_RampTex);

            // 정점 입력
            struct Attributes
            {
                float4 positionOS   : POSITION;
                float3 normalOS     : NORMAL;
            };

            // 정점 → 픽셀 셰이더로 넘길 데이터
            struct Varyings
            {
                float4 positionHCS  : SV_POSITION;
                float3 normalWS     : TEXCOORD0;
                float3 posWS        : TEXCOORD1;
            };

            // 정점 셰이더
            Varyings vert(Attributes IN)
            {
                Varyings OUT;
                OUT.positionHCS = TransformObjectToHClip(IN.positionOS);
                OUT.normalWS = TransformObjectToWorldNormal(IN.normalOS);
                OUT.posWS = TransformObjectToWorld(IN.positionOS.xyz);
                return OUT;
            }

            // 픽셀 셰이더
            half4 frag(Varyings IN) : SV_Target
            {
                // 1. 월드 공간에서 노멀 정규화
                float3 normalWS = normalize(IN.normalWS);

                // 2. 메인 라이트 가져오기 (URP 제공 함수)
                Light mainLight = GetMainLight();
                float3 lightDir = normalize(mainLight.direction);

                // 3. 내적 계산 (NdotL)
                float NdotL = dot(normalWS, lightDir);
                NdotL = saturate(NdotL * 0.5 + 0.5);

                // 4. 램프 텍스처 샘플링 (UV.y는 고정값)
                float3 ramp = SAMPLE_TEXTURE2D(_RampTex, sampler_RampTex, float2(NdotL, 0.5)).rgb;

                // 5. 최종 색상 = 기본색 × 램프값 × 광원색
                float3 finalColor = _Color.rgb * ramp * mainLight.color.rgb;

                return float4(finalColor, _Color.a);
            }
            ENDHLSL
        }
    }
}
```

---

### 법선과 광원 내적

```hlsl
float NdotL = dot(normalWS, lightDir);
NdotL = saturate(NdotL * 0.5 + 0.5);
```

* **dot(normal, lightDir)** : 표면이 광원과 얼마나 정면을 향하는지 계산
* `*0.5 + 0.5` : 범위를 `[-1,1] → [0,1]` 로 변환
* `saturate()` : 결과를 `0 ~ 1`로 제한

---

### Ramp Texture 샘플링

```hlsl
float3 ramp = SAMPLE_TEXTURE2D(_RampTex, sampler_RampTex, float2(NdotL, 0.5)).rgb;
```

* Toon Shading에서 **단계적 명암 처리**를 위해 1D Ramp Texture를 사용
* UV 좌표의 **x = NdotL**, **y = 0.5** (중앙 고정)

---

### 최종 색상 계산

```hlsl
float3 finalColor = _Color.rgb * ramp * mainLight.color.rgb;
```

* 기본 색상 × 램프 값 × 광원 색상
* 이렇게 하면 **단순 조명 + 셀 셰이딩** 효과 구현 가능

---

## Shader Graph 버전으로 구현하기

같은 원리를 Shader Graph에서도 쉽게 구현할 수 있습니다.

1. **Normal Vector** → **Dot Product (Light Direction)**
2. `NdotL * 0.5 + 0.5` 변환
3. **Sample Texture 2D (RampTex)**
4. **Color × Ramp × Light Color**

---

## 결과

* 단순한 URP Toon Shader 구현 가능
* **램프 텍스처만 바꾸면** 다양한 만화풍 명암 효과 연출 가능
* 추가로 `GetAdditionalLights()`를 사용하면 보조 광원 지원도 확장 가능


## **적용**

1. **램프 텍스처 준비**: 포토샵이나 그림판 같은 이미지 에디터로 256x16 픽셀 크기의 이미지를 만듭니다. 왼쪽은 어두운 색, 오른쪽은 밝은 색으로 채워서 그라데이션 램프나, 2\~3단계로 끊어지는 램프를 만듭니다.  

2. **Unity로 텍스처 가져오기**: 만든 텍스처를 Unity 프로젝트에 넣고, Inspector 창에서 Wrap Mode를 Clamp로 설정하여 가장자리가 반복되지 않도록 합니다.  

3. **Material 생성**: 셰이더를 오른쪽 클릭하고 Create \> Material을 선택하여 새 Material을 만듭니다.  

4. **Material 설정**: 생성된 Material을 선택하고 Inspector 창의 '램프 텍스처' 슬롯에 준비한 램프 텍스처를 끌어다 놓습니다.  

5. **오브젝트에 적용**: 씬에 있는 3D 모델에 이 Material을 적용하고, Directional Light를 움직여보면 명암이 램프 텍스처에 따라 뚜렷하게 바뀌는 것을 볼 수 있습니다.

이제 여러분은 툰 셰이딩의 가장 중요한 첫 단계를 마쳤습니다. 다음 단계에서는 이 모델에 외곽선을 추가해 보겠습니다.
