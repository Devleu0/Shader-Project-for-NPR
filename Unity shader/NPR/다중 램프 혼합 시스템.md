# **다중 램프 혼합 시스템**

## **목표**

하나의 램프 텍스처만 사용하는 것에서 벗어나, 특정 조명 환경(예: 따뜻한 조명, 차가운 조명)에 따라 여러 램프를 혼합하여 사용하는 시스템의 '개념'을 이해합니다.  
**주의**: 이 단계는 완전한 기능 구현보다는, 아이디어와 접근 방식을 설명하는 데 중점을 둡니다. 실제 구현은 셰이더뿐만 아니라 C\# 스크립팅과의 연동이 필요하여 복잡성이 높기 때문입니다.

## **다중 램프가 필요한가?**

캐릭터가 낮 장면에서는 따뜻한 느낌의 명암을, 밤이나 실내 장면에서는 차가운 느낌의 명암을 갖게 하고 싶을 수 있습니다. 이때 각 상황에 맞는 램프 텍스처를 미리 만들어두고, 현재 장면에 가장 적합한 램프를 사용하거나 여러 램프를 자연스럽게 섞어주면 훨씬 풍부한 아트 스타일을 연출할 수 있습니다.

## **스크립트를 이용한 전역 블렌딩 (간단한 방법)**

가장 직관적인 방법은 C\# 스크립트로 현재 씬의 조명 상태를 판단하여, 모든 NPR 셰이더에 "지금은 따뜻한 램프와 차가운 램프를 7:3 비율로 섞어라"와 같은 명령을 전역적으로 내리는 것입니다.

### **셰이더 코드 수정 (NPR Cel Shader.shader)**

두 개의 램프 텍스처와 그 둘을 섞을 혼합 비율(Blend) 프로퍼티를 추가합니다.  
`// Properties 블록`  
`_WarmRamp ("따뜻한 램프", 2D) = "white" {}`  
`_CoolRamp ("차가운 램프", 2D) = "white" {}`  
`_RampBlend ("램프 혼합 비율", Range(0, 1)) = 0`

LightingToon 함수에서 두 램프를 읽고 lerp 함수로 혼합합니다.  
`// LightingToon 함수 내부`  
`// ...`  
`sampler2D _WarmRamp;`  
`sampler2D _CoolRamp;`  
`half _RampBlend;`

`// ...`  
`half4 LightingToon(...) {`  
    `// ... NdotL 계산 ...`  
    `half NdotL = dot(s.Normal, lightDir) * 0.5 + 0.5;`

    `// 두 개의 램프 텍스처에서 각각 색상을 읽어옵니다.`  
    `half3 warm = tex2D(_WarmRamp, float2(NdotL, 0.5)).rgb;`  
    `half3 cool = tex2D(_CoolRamp, float2(NdotL, 0.5)).rgb;`

    `// _RampBlend 값에 따라 두 색상을 선형 보간(lerp)합니다.`  
    `// _RampBlend가 0이면 warm, 1이면 cool, 0.5면 절반씩 섞입니다.`  
    `half3 ramp = lerp(warm, cool, _RampBlend);`

    `// ... 최종 색상 계산 ...`  
`}`

### **제어 스크립트 작성 (LightingManager.cs)**

씬의 조명을 관리하는 C\# 스크립트를 만듭니다. 이 스크립트는 씬에 있는 주 광원(Directional Light)의 색상을 체크하여, 모든 셰이더의 \_RampBlend 값을 한 번에 변경합니다.  
`using UnityEngine;`

`[ExecuteInEditMode] // 에디터 모드에서도 실행되도록 설정`  
`public class LightingManager : MonoBehaviour`  
`{`  
    `public Light mainLight; // 씬의 주 광원을 연결`  
    `public float blendValue; // 현재 블렌드 값 (디버깅용)`

    `void Update()`  
    `{`  
        `if (mainLight == null) return;`

        `// 주 광원의 색상을 기준으로 따뜻한지 차가운지 판단 (단순한 예시)`  
        `// r 값이 g, b 값보다 높으면 따뜻한 톤으로 간주`  
        `bool isWarm = mainLight.color.r > mainLight.color.g && mainLight.color.r > mainLight.color.b;`

        `// 부드럽게 블렌드 값을 변경`  
        `float targetBlend = isWarm ? 0.0f : 1.0f;`  
        `blendValue = Mathf.Lerp(blendValue, targetBlend, Time.deltaTime * 1.0f);`

        `// Shader.SetGlobalFloat를 사용하여 모든 셰이더의 "_RampBlend" 값을 한 번에 설정`  
        `Shader.SetGlobalFloat("_RampBlend", blendValue);`  
    `}`  
`}`

**사용법**

1. 씬에 빈 게임 오브젝트를 만들고 LightingManager 스크립트를 붙입니다.  
2. Main Light 필드에 씬의 Directional Light를 연결합니다.  
3. 이제 Directional Light의 색상을 노란색 계열로 바꾸면 캐릭터가 따뜻한 램프를 사용하고, 파란색 계열로 바꾸면 차가운 램프를 사용하는 것을 볼 수 있습니다.

## **다중 라이트 지원**

Forward Rendering 경로에서 여러 광원을 처리하며 각 광원마다 다른 램프를 적용하는 것은 훨씬 복잡합니다. 이를 위해서는:

1. **추가 광원 Pass**: \#pragma multi\_compile\_fwdadd 지시어를 사용하여 추가 광원을 위한 Pass를 만들어야 합니다.  
2. **광원 데이터 전달**: C\# 스크립트를 통해 각 광원의 정보(색온도, 커스텀 태그 등)를 셰이더로 전달해야 합니다. 이는 MaterialPropertyBlock이나 전역 셰이더 배열을 사용하는 등 고급 기법이 필요합니다.  
3. **셰이더 내 로직**: 셰이더는 전달받은 데이터를 기반으로 각 광원에 대해 어떤 램프를 사용할지 결정하고 그 결과를 누적하여 합산해야 합니다.

이 방법은 높은 자유도를 제공하지만, 튜토리얼의 범위를 넘어서는 깊이 있는 셰이더 및 스크립팅 지식이 필요합니다. 대부분의 프로젝트에서는 **접근 방법 1**을 응용하는 것만으로도 충분히 원하는 아트 스타일을 구현할 수 있습니다.  
이것으로 NPR 셰이더 제작의 모든 단계를 마쳤습니다. 이제 이 개념들을 조합하여 여러분만의 독특한 스타일을 만들어보세요\!
