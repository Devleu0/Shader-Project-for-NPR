# 4. 다중 램프 혼합 시스템

> 코드: `NPRToonPass.hlsl` (램프 lerp), `NPRInput.hlsl` (`_NPR_RampBlend`), `Assets/Scripts/NPR/NPRRampBlendController.cs`

## 목표
낮/따뜻한 조명에서는 Warm 램프, 밤/차가운 조명에서는 Cool 램프를 쓰도록 **모든 NPR 머티리얼을 한 번에** 제어합니다.

## 셰이더 쪽
```hlsl
half3 warm = SAMPLE_TEXTURE2D(_WarmRamp, sampler_point_clamp, rampUV).rgb;
half3 cool = SAMPLE_TEXTURE2D(_CoolRamp, sampler_point_clamp, rampUV).rgb;
half3 ramp = lerp(warm, cool, saturate(_NPR_RampBlend));
```

### ⚠ 전역 값과 Properties 의 함정
이전 문서는 `_RampBlend` 를 **Properties 에 선언**하고 C# 에서 `Shader.SetGlobalFloat("_RampBlend", …)` 를 호출했습니다. 이렇게 하면 머티리얼 프로퍼티가 전역 값을 가리기 때문에 **스크립트가 아무 효과가 없습니다.**
전역으로 제어할 값은 Properties 에 쓰지 않고 HLSL 변수로만 선언합니다 (`float _NPR_RampBlend;`, CBUFFER 밖).

## C# 쪽
`NPRRampBlendController` 를 빈 오브젝트에 붙이고 Main Light 슬롯에 Directional Light 를 연결합니다.
- 빛 색의 `r >= b` 이면 Warm(0), 아니면 Cool(1) 을 목표로 하고
- 재생 중에는 `Mathf.SmoothDamp` 로 부드럽게 전환, 에디터에서는 즉시 반영합니다. (`[ExecuteAlways]`)

테스트: Light 색을 주황 → 하늘색으로 바꾸며 명암 색이 변하는지 확인합니다.

## 한계와 확장
- 지금은 *메인 라이트 하나*만 처리합니다. 추가 라이트(Point/Spot)별로 램프를 달리하려면 `GetAdditionalLightsCount()`/`GetAdditionalLight(i, positionWS)` 루프를 `ToonFrag` 에 넣고, 각 라이트 결과를 누적합니다. (URP 의 `Additional Lights` 설정을 Per Pixel 로 하고 `#pragma multi_compile _ _ADDITIONAL_LIGHTS` 필요)
- 색 온도 판정이 단순한 r/b 비교입니다. `Light.useColorTemperature` / 색상 HSV 를 이용해 개선해 보세요.
