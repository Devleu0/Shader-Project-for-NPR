# 3. 림 라이트와 스페큘러

> 코드: [README 의 전체 코드](./README.md#전체-코드) 중 `NPRToonPass.hlsl` 의 `ToonFrag` 뒷부분

## 스페큘러 (딱딱한 하이라이트)
Blinn-Phong 의 `pow(N·H, n)` 을 `step` 으로 잘라 경계가 뚜렷한 흰 점을 만듭니다.

```hlsl
float3 halfDir = normalize(lightDir + viewDir);
half exponent  = max(1.0h, _Glossiness * 128.0h);
half spec = pow(saturate(dot(normalWS, halfDir)), exponent);
spec = step(_SpecularThreshold, spec) * shadow;
```
- `H = normalize(L + V)` : 빛 방향과 시선 방향의 중간 벡터. `N` 과 가까울수록 정반사 위치.
- 지수를 `max(1, …)` 로 보호하는 이유: `_Glossiness = 0` 이면 `pow(x, 0) = 1` 이 되어 **모든 픽셀이 하이라이트** 가 되기 때문입니다.
- `_SpecularThreshold` 를 높이면 하이라이트가 작아지고, 낮추면 커집니다. (`_Glossiness` 도 크기에 영향)
- 그림자 안에는 하이라이트가 생기지 않게 `shadow` 를 곱합니다.

## 림 라이트
시선과 법선이 수직에 가까운 가장자리를 밝힙니다.

```hlsl
half rim = 1.0h - saturate(dot(viewDir, normalWS));
rim = pow(rim, _RimSharpness);
rim = smoothstep(_RimWidth, 1.0h, rim);
color += _RimColor.rgb * rim;
```
- `dot(V, N)` 은 정면에서 1, 가장자리에서 0 → `1 - dot` 으로 뒤집어 가장자리를 1 로 만듭니다.
- `_RimWidth` 는 림이 시작되는 임계값, `_RimSharpness` 는 지수입니다.
- 툰 느낌을 더 강하게 하려면 `smoothstep` 의 두 값을 아주 가깝게(예: 0.7, 0.72) 두면 계단처럼 딱 잘립니다.

## 실습
1. `_SpecularThreshold` 를 0.5 → 1.0 으로 움직여 하이라이트 크기 변화를 본다.
2. `_Glossiness` 를 0 으로 놓고도 화면이 깨지지 않는지 확인한다.
3. `smoothstep(_RimWidth, _RimWidth + 0.02, rim)` 으로 바꿔 만화식 림을 만든다.
