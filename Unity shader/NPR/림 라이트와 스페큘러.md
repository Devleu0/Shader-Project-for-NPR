# **3단계: 디테일 추가 \- 림 라이트와 스페큘러**

## **목표**

캐릭터를 더욱 입체적이고 생동감 있게 만들어주는 림 라이트(Rim Light)와 반짝이는 하이라이트(Specular) 효과를 추가합니다.


### **1\. 림 라이트 (Rim Light)**

림 라이트는 물체의 가장자리, 즉 시선과 표면이 거의 수직을 이루는 부분에 빛이 비치는 효과입니다. 캐릭터의 실루엣을 강조하고 배경과 분리시켜주는 역할을 하여 입체감을 크게 향상시킵니다.

* **계산 원리**: 카메라(시선) 방향 벡터와 표면의 법선(Normal) 벡터를 내적(dot product)합니다. 두 벡터가 90도에 가까울수록(내적 결과가 0에 가까울수록) 가장자리 부분이므로, 림 라이트가 강하게 나타나도록 계산합니다. 1 \- dot(viewDir, normal) 공식을 주로 사용하며, 결과값을 pow() 함수로 조절하여 날카로움을 제어합니다.

### **2\. 스페큘러 (Specular)**

스페큘러는 광원에서 나온 빛이 표면에서 정반사되어 우리 눈에 직접 들어오는 '반짝임' 효과입니다. 카툰 렌더링에서는 부드러운 하이라이트 대신, 원이나 타원 형태의 뚜렷하고 딱딱한 하이라이트를 만들어 애니메이션 느낌을 강조합니다.

* **계산 원리**: 빛 방향과 시선 방향의 중간 벡터(Half Vector)와 표면의 법선 벡터를 내적합니다. 이 값이 클수록 시선이 정반사 위치에 가깝다는 의미입니다. 이 결과값을 특정 임계값(Threshold)과 비교하여 하이라이트를 그릴지 말지 결정함으로써 딱딱한 경계를 만듭니다.

## **셰이더 코드 수정**

NPR\_Cel\_Shader.shader 파일의 첫 번째 Pass(본체 그리기) 부분을 수정합니다.

### **1\. Properties 추가**

림 라이트와 스페큘러를 제어할 프로퍼티를 Properties 블록에 추가합니다.  
`// Properties 블록에 추가`  
`_RimColor ("림 라이트 색상", Color) = (1,1,1,1)`  
`_RimWidth ("림 라이트 범위", Range(0, 1)) = 0.7`  
`_RimSharpness ("림 라이트 경계", Range(1, 5)) = 3.0`

`_SpecularColor ("스페큘러 색상", Color) = (1,1,1,1)`  
`_Glossiness ("광택", Range(0, 1)) = 0.5`

* \_RimWidth: 림 라이트가 시작되는 지점을 제어합니다. (1에 가까울수록 좁아짐)  
* \_RimSharpness: 림 라이트의 경계를 얼마나 날카롭게 만들지 결정합니다.  
* \_Glossiness: 스페큘러 하이라이트의 크기와 선명도를 조절합니다.

### **2\. surf 함수 수정 및 Input 구조체 확장**

림 라이트와 스페큘러 계산에는 카메라의 시선 방향(viewDir)이 필요합니다. Input 구조체에 viewDir를 추가하여 surf 함수에서 사용할 수 있도록 합니다.  
`// ... CGPROGRAM 내부 ...`

`// Input 구조체에 viewDir 추가`  
`struct Input {`  
    `float2 uv_MainTex;`  
    `float3 viewDir; // 시선 방향 벡터`  
`};`

`// 프로퍼티 변수 선언`  
`sampler2D _RampTex;`  
`fixed4 _Color;`  
`fixed4 _RimColor;`  
`half _RimWidth;`  
`half _RimSharpness;`  
`fixed4 _SpecularColor;`  
`half _Glossiness;`

`// surf 함수 수정`  
`void surf (Input IN, inout SurfaceOutput o) {`  
    `o.Albedo = _Color.rgb;`  
    `o.Alpha = _Color.a;`

    `// --- 림 라이트 계산 ---`  
    `// 시선 방향과 노멀 방향을 내적합니다.`  
    `half dotViewNormal = dot (normalize(IN.viewDir), o.Normal);`  
      
    `// 가장자리일수록(dotViewNormal이 0에 가까울수록) 1에 가까운 값을 갖도록 계산합니다.`  
    `half rim = 1.0 - saturate(dotViewNormal);`  
      
    `// _RimWidth로 범위를 조절하고, _RimSharpness로 경계를 날카롭게 만듭니다.`  
    `rim = pow(rim, _RimSharpness);`  
    `rim = smoothstep(_RimWidth, 1.0, rim); // smoothstep을 사용해 부드러운 경계 시작`

    `// o.Emission에 림 라이트 색상을 더해 발광 효과처럼 표현합니다.`  
    `o.Emission = _RimColor.rgb * rim;`  
`}`

### **3\. 커스텀 라이팅 모델(LightingToon) 수정**

스페큘러는 광원의 위치와 직접적인 관련이 있으므로, LightingToon 함수 안에서 계산하는 것이 효율적입니다.  
`// LightingToon 함수 수정`

`// 스페큘러 계산을 위해 viewDir가 필요하므로 함수의 인자로 추가합니다.`  
`half4 LightingToon (SurfaceOutput s, half3 lightDir, half3 viewDir, half atten) {`  
    `half NdotL = dot (s.Normal, lightDir);`  
    `NdotL = NdotL * 0.5 + 0.5;`  
    `half3 ramp = tex2D(_RampTex, float2(NdotL, 0.5)).rgb;`

    `// --- 스페큘러 계산 ---`  
    `// 빛 방향과 시선 방향의 중간 벡터를 계산합니다.`  
    `half3 halfVector = normalize(lightDir + viewDir);`  
    `// 노멀과 중간 벡터를 내적하고, _Glossiness로 선명도를 조절합니다.`  
    `float NdotH = pow(saturate(dot(s.Normal, halfVector)), _Glossiness * 128); // 128은 임의의 승수`

    `// 특정 임계값을 기준으로 딱딱한 하이라이트를 만듭니다.`  
    `float specular = step(0.9, NdotH); // 0.9보다 크면 1, 작으면 0`  
      
    `// 최종 색상 계산`  
    `half4 c;`  
    `// (표면색 * 명암) + 스페큘러 색상`  
    `c.rgb = (s.Albedo * ramp * (atten * 2)) + (_SpecularColor.rgb * specular);`  
    `c.a = s.Alpha;`  
    `return c;`  
`}`

\#pragma surface 지시자도 viewDir를 사용하도록 수정해야 합니다.  
`// #pragma surface 라인 수정`  
`#pragma surface surf Toon viewDir`

viewDir를 추가하면 Unity가 자동으로 surf와 LightingToon 함수에 시선 방향 벡터를 전달해 줍니다.

## **적용 및 테스트**

코드를 저장하고 Unity로 돌아오면 Material Inspector에서 림 라이트와 스페큘러 관련 파라미터들을 조절할 수 있습니다.

* **림 라이트**: Rim Color, Rim Width, Rim Sharpness를 조절하며 캐릭터의 실루엣이 어떻게 강조되는지 확인해보세요.  
* **스페큘러**: Directional Light의 각도를 바꿔가며 하이라이트가 어떻게 나타나는지 보세요. Glossiness 값을 높이면 하이라이트가 더 작고 선명해집니다.

이제 셰이더는 기본 툰 셰이딩, 외곽선, 림 라이트, 스페큘러까지 갖추게 되었습니다. 마지막 단계에서는 여러 개의 램프 텍스처를 상황에 맞게 혼합하는 고급 개념에 대해 알아보겠습니다.
