# **역면 확장 기법으로 외곽선 그리기**

## **목표**

캐릭터나 사물의 외곽선을 그려 만화적인 느낌을 한층 더 강화합니다. 우리는 가장 널리 쓰이고 안정적인 기법 중 하나인 **'역면 확장(Inverted Hull)'** 기법을 사용할 것입니다.

## **역면 확장 (Inverted Hull)**

이 기법은 두 번의 그리기(Pass) 과정을 통해 작동합니다.

1. **첫 번째 Pass (본체 그리기)**: 이전 1단계에서 만들었던 것처럼 모델의 본체를 정상적으로 그립니다.  
2. **두 번째 Pass (외곽선 그리기)**:  
   * 모델의 모든 폴리곤(면)을 뒤집습니다. 즉, 모델의 안쪽 면이 바깥쪽을 향하게 만듭니다. (Unity에서는 Cull Front로 설정)  
   * 뒤집힌 모델의 모든 정점(Vertex)을 각 정점의 법선(Normal) 방향으로 아주 약간씩 밀어내어 모델을 전체적으로 '확장'시킵니다.  
   * 확장된 모델을 단색으로 칠합니다.

이렇게 하면, 원래 모델보다 약간 더 큰 뒤집힌 모델이 본체 뒤에 그려지게 되고, 그 가장자리 부분이 마치 '외곽선'처럼 보이게 됩니다.

## **셰이더에 외곽선 Pass 추가하기**

NPR\_Cel\_Shader.shader 파일을 열고 코드를 수정합니다.

### **1. Properties 추가**

외곽선의 색상과 두께를 조절할 수 있는 프로퍼티를 추가합니다.  
`// Properties 블록에 추가`  
`_OutlineColor ("외곽선 색상", Color) = (0,0,0,1)`  
`_OutlineThickness ("외곽선 두께", Range(0, 0.1)) = 0.01`  
`_OutlineDistanceFade ("거리 비례 두께 (시작, 끝)", Vector) = (10, 50, 0, 0)`

* \_OutlineThickness: 외곽선의 기본 두께를 조절합니다.  
* \_OutlineDistanceFade: 카메라와의 거리에 따라 외곽선 두께가 얇아지도록 제어합니다. x는 얇아지기 시작하는 거리, y는 완전히 사라지는 거리입니다.

### **2. 외곽선 Pass 작성**

기존 SubShader 안에 있던 CGPROGRAM ... ENDCG 블록 바로 다음에, 외곽선을 위한 새로운 Pass를 추가합니다.  
`// ... 기존 SubShader의 끝 부분 ...`  
        `ENDCG // 여기가 첫 번째 Pass의 끝입니다.`

        `//       두 번째 Pass: 외곽선 그리기`  
        `Pass`  
        `{`  
            `// 앞면을 컬링(그리지 않음)하여 뒷면만 보이게 합니다.`  
            `Cull Front`  
            `// 그림자를 드리우지 않도록 설정합니다.`  
            `Tags { "LightMode"="ShadowCaster" }`

            `CGPROGRAM`  
            `#pragma vertex vert`  
            `#pragma fragment frag`  
            `#include "UnityCG.cginc"`

            `// 프로퍼티에서 변수를 받아옵니다.`  
            `float4 _OutlineColor;`  
            `float _OutlineThickness;`  
            `float4 _OutlineDistanceFade;`

            `// 정점 셰이더 입력 구조체`  
            `struct appdata`  
            `{`  
                `float4 vertex : POSITION;`  
                `float3 normal : NORMAL;`  
            `};`

            `// 정점 셰이더 출력 구조체 (프래그먼트 셰이더로 전달)`  
            `struct v2f`  
            `{`  
                `float4 pos : SV_POSITION;`  
            `};`

            `// 정점 셰이더 (Vertex Shader)`  
            `v2f vert (appdata v)`  
            `{`  
                `v2f o;`

                `// 1. 카메라와의 거리 계산`  
                `// 월드 좌표계에서 정점의 위치와 카메라 위치 사이의 거리를 구합니다.`  
                `float3 worldPos = mul(unity_ObjectToWorld, v.vertex).xyz;`  
                `float distance = length(worldPos - _WorldSpaceCameraPos);`

                `// 2. 거리에 따른 두께 보정 계수 계산`  
                `// _OutlineDistanceFade.x (시작 거리)와 .y (끝 거리) 사이에서 값이 1에서 0으로 변합니다.`  
                `float distanceFade = 1.0 - saturate((distance - _OutlineDistanceFade.x) / (_OutlineDistanceFade.y - _OutlineDistanceFade.x));`

                `// 3. 최종 두께 계산`  
                `float finalThickness = _OutlineThickness * distanceFade;`

                `// 4. 정점을 노멀 방향으로 확장`  
                `// 뷰 좌표계에서 노멀 방향으로 밀어내야 원근감에 의해 두께가 왜곡되는 것을 방지할 수 있습니다.`  
                `float4 viewPos = mul(UNITY_MATRIX_MV, v.vertex);`  
                `float3 viewNormal = mul((float3x3)UNITY_MATRIX_IT_MV, v.normal);`  
                `viewPos.xyz += normalize(viewNormal) * finalThickness;`

                `// 5. 클립 공간으로 변환하여 최종 위치 결정`  
                `o.pos = mul(UNITY_MATRIX_P, viewPos);`  
                `return o;`  
            `}`

            `// 프래그먼트(픽셀) 셰이더 (Fragment Shader)`  
            `fixed4 frag (v2f i) : SV_Target`  
            `{`  
                `// 모든 픽셀을 외곽선 색상으로 칠합니다.`  
                `return _OutlineColor;`  
            `}`  
            `ENDCG`  
        `} // 여기가 두 번째 Pass의 끝입니다.`

### **코드 주요 설명**

* **Cull Front** 폴리곤의 앞면을 그리지 않겠다는 의미입니다. 따라서 모델의 내부, 즉 뒷면만 렌더링됩니다.  
* **Vertex Shader (vert)** 모델의 각 정점이 화면에 그려지기 전에 위치를 조작하는 역할을 합니다.  
  * **거리 계산** WorldSpaceCameraPos (Unity 내장 변수)를 이용해 카메라와 정점 사이의 거리를 계산합니다.  
  * **두께 보정** saturate 함수를 이용해 거리에 따라 두께를 0\~1 사이 값으로 조절하는 distanceFade 계수를 만듭니다.  
  * **정점 확장** 계산된 최종 두께(finalThickness)만큼 정점을 법선 방향으로 밀어냅니다. 이때, 뷰 공간(View Space)에서 계산해야 카메라 시점에 상관없이 일정한 두께를 유지할 수 있습니다.  
* **Fragment Shader (frag)** 각 픽셀의 최종 색상을 결정합니다. 외곽선은 단색이므로,  OutlineColor를 그대로 반환하면 됩니다.

## **적용 및 테스트**

셰이더 코드를 저장하고 Unity 에디터로 돌아오면, Material Inspector에 '외곽선 색상', '외곽선 두께', '거리 비례 두께' 파라미터가 새로 생긴 것을 볼 수 있습니다.

* **두께 조절** '외곽선 두께' 슬라이더를 조절하여 외곽선의 굵기를 바꿔보세요.  
* **거리 페이드 테스트** 카메라를 모델에서 멀리 떨어뜨리거나 가깝게 이동시키면서 외곽선이 부드럽게 얇아지거나 사라지는지 확인하세요. '거리 비례 두께'의 X, Y 값을 조절하여 페이드가 시작되고 끝나는 거리를 설정할 수 있습니다.

이제 모델은 뚜렷한 명암과 함께 깔끔한 외곽선을 가지게 되었습니다. 다음 단계에서는 여기에 림 라이트와 스페큘러를 추가하여 퀄리티를 더욱 높여보겠습니다.
