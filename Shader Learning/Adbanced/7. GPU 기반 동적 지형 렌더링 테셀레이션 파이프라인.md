## GPU 기반 동적 지형 렌더링: 테셀레이션 파이프라인 마스터하기
이 문서는 DirectX 11의 테셀레이션 파이프라인을 활용하여, 카메라 거리에 따라 디테일 수준(LOD)이 동적으로 변화하는 광활하고 사실적인 지형을 렌더링하는 방법을 심도 있게 다룹니다.

### 왜 테셀레이션 지형인가?
광활한 월드를 구현할 때 가장 큰 난관은 '성능'과 '디테일' 사이의 균형입니다.

* 고해상도 메시: 처음부터 수백만 개의 폴리곤으로 이루어진 지형을 사용하면 가까이서 볼 때는 디테일이 뛰어나지만, 메모리 사용량이 막대하고 렌더링 성능이 급격히 저하됩니다.

* 저해상도 메시: 멀리서 볼 때는 문제가 없지만, 가까이 다가가면 각진 지형이 그대로 드러나 몰입감을 해칩니다.

테셀레이션은 이 문제를 GPU 단에서 해결합니다. 우리는 아주 성긴(low-poly) 기본 메시만 GPU에 넘겨주고, 렌더링 파이프라인 중간에서 GPU가 직접 이 메시를 수많은 작은 삼각형으로 잘게 쪼개어 디테일을 '창조'하도록 합니다. 특히 카메라에 가까운 부분은 더 잘게, 먼 부분은 덜 잘게 쪼개어 동적 LOD를 완벽하게 구현할 수 있습니다.

### 테셀레이션 렌더링 파이프라인
테셀레이션을 사용하면 기존의 정점/픽셀 셰이더 사이에 3개의 새로운 단계가 추가됩니다.

* 정점 셰이더 (Vertex Shader): 지형을 구성하는 큰 사각형 패치(Patch)의 제어점(Control Point)들을 받아 헐 셰이더로 넘기는, 비교적 간단한 역할만 수행합니다.

* (신규) 헐 셰이더 (Hull Shader, HS): 테셀레이션의 '두뇌'입니다.

* 상수 함수 (Constant Function): 패치(Patch)가 카메라로부터 얼마나 멀리 떨어져 있는지 계산하여, 이 패치를 **얼마나 잘게 쪼갤지(Tessellation Factor)**를 결정합니다.

* 제어점 함수 (Control Point Function): 제어점 데이터를 가공하여 도메인 셰이더로 넘겨줄 준비를 합니다.

* (신규) 테셀레이터 (Tessellator): 하드웨어 고정 단계입니다. 헐 셰이더가 결정한 Tessellation Factor에 따라, 패치를 실제로 잘게 쪼개어 수많은 새로운 정점들의 '위치 정보(Barycentric Coordinate)'를 생성합니다.

* (신규) 도메인 셰이더 (Domain Shader, DS): 테셀레이션의 '아티스트'입니다. 테셀레이터가 생성한 수많은 새 정점들을 입력받아, **하이트맵(Height Map)**을 참조하여 각 정점의 최종 3D 위치(특히 높이)를 결정합니다.

* 픽셀 셰이더 (Pixel Shader): 도메인 셰이더가 완성한 최종 지형 표면에 색상과 재질을 입힙니다.

핵심 요소: 하이트맵 (Height Map)
* 하이트맵은 지형의 높낮이 정보를 담고 있는 흑백 텍스처입니다. 검은색(0)은 가장 낮은 지역을, 흰색(1)은 가장 높은 지역을 의미합니다. 도메인 셰이더는 이 텍스처를 샘플링하여 평평한 격자 위의 정점들을 위아래로 움직여(Displacement) 산과 계곡을 만들어냅니다.

### HLSL 구현
1. 정점 셰이더 (Vertex Shader)
입력된 제어점의 위치를 그대로 헐 셰이더로 전달합니다.
```hlsl
// 제어점의 입력/출력 구조체
struct VS_OUTPUT
{
    float3 Pos : POSITION;
};

VS_OUTPUT VS(float3 pos : POSITION)
{
    VS_OUTPUT output;
    output.Pos = pos;
    return output;
}
```
2. 헐 셰이더 (Hull Shader)
카메라 거리에 따라 테셀레이션 강도를 결정하는 핵심 부분입니다.
```hlsl
// 제어점 데이터를 HS -> DS로 전달하기 위한 구조체
struct HS_OUTPUT
{
    float3 Pos : POSITION;
};

// HS의 상수 함수 출력 구조체 (테셀레이션 팩터)
struct HS_CONSTANT_DATA_OUTPUT
{
    float EdgeTessFactor[4] : SV_TessFactor; // 사각형 패치의 4개 외곽선
    float InsideTessFactor[2] : SV_InsideTessFactor; // 사각형 패치의 내부
};

// 상수 함수: 패치당 한 번 호출됨
HS_CONSTANT_DATA_OUTPUT HSConstantFunction(InputPatch<VS_OUTPUT, 4> inputPatch)
{
    HS_CONSTANT_DATA_OUTPUT output;
    
    // 패치의 중심점 계산
    float3 patchCenter = (inputPatch[0].Pos + inputPatch[1].Pos + inputPatch[2].Pos + inputPatch[3].Pos) / 4.0;
    
    // 카메라와의 거리 계산
    float dist = distance(patchCenter, CameraPos.xyz);
    
    // 거리에 따른 테셀레이션 팩터 계산 (가까우면 64, 멀면 1)
    // maxTess: 최대 테셀레이션 레벨, min/maxDistance: LOD 변화 거리
    float tessFactor = lerp(64.0f, 1.0f, saturate((dist - 10.0f) / 200.0f));
    
    // 모든 외곽선과 내부에 동일한 팩터 적용
    output.EdgeTessFactor[0] = output.EdgeTessFactor[1] = output.EdgeTessFactor[2] = output.EdgeTessFactor[3] = tessFactor;
    output.InsideTessFactor[0] = output.InsideTessFactor[1] = tessFactor;
    
    return output;
}

// 메인 함수: 각 제어점마다 호출됨
[domain("quad")]
[partitioning("integer")]
[outputtopology("triangle_cw")]
[outputcontrolpoints(4)]
[patchconstantfunc("HSConstantFunction")]
HS_OUTPUT HS(InputPatch<VS_OUTPUT, 4> inputPatch, uint i : SV_OutputControlPointID)
{
    HS_OUTPUT output;
    output.Pos = inputPatch[i].Pos;
    return output;
}
```
3. 도메인 셰이더 (Domain Shader)
새로 생성된 정점들의 최종 위치를 하이트맵을 이용해 결정합니다.
```hlsl
Texture2D HeightMap;
SamplerState HeightSampler;

// 도메인 셰이더 출력 (픽셀 셰이더 입력)
struct DS_OUTPUT
{
    float4 Pos : SV_POSITION;
    float2 Tex : TEXCOORD0;
    float3 WorldPos : TEXCOORD1;
};

[domain("quad")]
DS_OUTPUT DS(HS_CONSTANT_DATA_OUTPUT hsConst, const OutputPatch<HS_OUTPUT, 4> inputPatch, float2 domainLoc : SV_DomainLocation)
{
    DS_OUTPUT output;

    // 1. 도메인 위치(domainLoc)를 이용해 패치 내의 평면상 위치(x, z)를 보간
    float3 worldPos = lerp(
        lerp(inputPatch[0].Pos, inputPatch[1].Pos, domainLoc.x),
        lerp(inputPatch[3].Pos, inputPatch[2].Pos, domainLoc.x),
        domainLoc.y
    );

    // 2. UV 좌표 계산 및 하이트맵 샘플링
    output.Tex = worldPos.xz / TerrainSize; // TerrainSize는 전체 지형 크기
    float height = HeightMap.SampleLevel(HeightSampler, output.Tex, 0).r;

    // 3. 하이트맵 값을 이용해 높이(y) 적용 (Displacement)
    worldPos.y = height * MaxHeight; // MaxHeight는 최대 높이

    // 4. 최종 화면 위치 계산 및 픽셀 셰이더로 데이터 전달
    output.WorldPos = worldPos;
    output.Pos = mul(float4(worldPos, 1.0f), WorldViewProj);
    
    return output;
}
```
4. 픽셀 셰이더 (Pixel Shader)
지형의 높이에 따라 색상을 입혀 시각화합니다.
```hlsl
float4 PS(DS_OUTPUT input) : SV_Target
{
    // 높이에 따라 색상을 다르게 표현 (낮은 곳: 녹색, 높은 곳: 흰색)
    float heightPercent = saturate(input.WorldPos.y / MaxHeight);
    float3 grass = float3(0.2, 0.6, 0.2);
    float3 snow = float3(1.0, 1.0, 1.0);
    
    float3 finalColor = lerp(grass, snow, pow(heightPercent, 2.0));
    
    // (여기에 텍스처 스플래팅, 조명 계산 등을 추가할 수 있음)
    
    return float4(finalColor, 1.0);
}
```
다음 단계: 디테일 향상
* 텍스처 스플래팅 (Texture Splatting): 지형의 높이나 경사도에 따라 잔디, 흙, 암석, 눈 등 여러 텍스처를 자연스럽게 섞어 사실감을 더합니다.

* 지오모핑 (Geomorphing): LOD 레벨이 변할 때 지형이 갑자기 튀는(popping) 현상을 막기 위해, LOD 경계의 정점들을 부드럽게 보간하는 기법입니다.

* 프러스텀 컬링 (Frustum Culling): 헐 셰이더 단계에서 카메라 시야각 밖에 있는 패치는 아예 테셀레이션을 수행하지 않도록(Tessellation Factor = 0) 하여 성능을 최적화합니다.
