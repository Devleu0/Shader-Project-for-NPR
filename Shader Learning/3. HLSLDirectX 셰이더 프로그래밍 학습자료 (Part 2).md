HLSL/DirectX 셰이더 프로그래밍 학습자료 (Part 2)
이 문서는 Part 1에서 배운 기본 셰이더 개념을 바탕으로, 보다 사실적이고 다채로운 3D 장면을 만들기 위한 중급 셰이딩 기법들을 소개합니다. 각 주차별로 고급 조명, 표면 디테일, 그림자, 반사 효과를 단계적으로 학습합니다.

5주차: 고급 조명 기법
🎯 학습 목표:

퐁(Phong) 조명 모델을 개선하여 더 효율적이고 자연스러운 반사광을 만듭니다.

재질(Material) 시스템을 도입하여 물체마다 다른 표면 특성을 부여합니다.

핵심 이론
블린-퐁 조명 모델 (Blinn-Phong Lighting Model)
퐁 모델의 정반사광(Specular) 계산은 reflect 함수를 사용하여 연산 비용이 다소 높고, 특정 각도에서 하이라이트가 급격히 사라지는 단점이 있습니다. 블린-퐁은 이를 '중간 벡터(Halfway Vector)' 개념을 도입하여 개선합니다.

중간 벡터 (H): 광원 방향 벡터(L)와 시선 방향 벡터(V)의 정확히 중간을 향하는 벡터입니다. (H = normalize(L + V))

계산: 이 중간 벡터(H)와 법선 벡터(N)가 얼마나 가까운지를 계산(dot(N, H))하여 하이라이트를 표현합니다. 이 방식은 연산이 더 빠르고, 더 부드럽고 넓은 하이라이트를 만들어 줍니다.

재질 (Material) 시스템
현실의 물체들은 저마다 다른 광학적 특성을 가집니다. (예: 플라스틱의 반사광과 금속의 반사광은 다름) 이를 표현하기 위해 물체의 색상과 반사 특성을 정의하는 데이터 묶음을 '재질'이라고 합니다.

재질 속성:

Ambient: 환경광에 반응하는 색상

Diffuse: 난반사광에 반응하는 색상 (물체의 고유 색)

Specular: 정반사광의 색상 (하이라이트의 색)

Shininess: 반짝임의 정도 (하이라이트의 크기)

HLSL 실습 코드: 재질을 적용한 블린-퐁 조명
// 재질 정보를 담을 상수 버퍼
cbuffer CBufferPerMaterial
{
    float4 MatAmbient;
    float4 MatDiffuse;
    float4 MatSpecular; // w 요소에 Shininess 저장
}

// ... (기존 CBufferPerFrame, VS_INPUT, PS_INPUT 구조체) ...

float4 PS(PS_INPUT input) : SV_Target
{
    // 텍스처에서 기본 색상 가져오기
    float4 textureColor = ObjTexture.Sample(ObjSampler, input.Tex);

    // 벡터들 정규화
    float3 normal = normalize(input.Normal);
    float3 lightDir = normalize(-LightDir.xyz);
    float3 viewDir = normalize(CameraPos.xyz - input.WorldPos);

    // 1. 환경광 (Ambient)
    float3 ambient = LightColor.rgb * MatAmbient.rgb;

    // 2. 난반사광 (Diffuse)
    float diffFactor = saturate(dot(normal, lightDir));
    float3 diffuse = diffFactor * LightColor.rgb * MatDiffuse.rgb;

    // 3. 정반사광 (Specular) - 블린-퐁 방식
    float3 halfwayDir = normalize(lightDir + viewDir); // 중간 벡터 계산
    float specFactor = pow(saturate(dot(normal, halfwayDir)), MatSpecular.w); // N과 H의 내적
    float3 specular = specFactor * LightColor.rgb * MatSpecular.rgb;

    // 최종 색상 = (환경광 + 난반사광) * 텍스처 색 + 정반사광
    float3 finalColor = (ambient + diffuse) * textureColor.rgb + specular;

    return float4(finalColor, textureColor.a);
}

✅ 5주차 연습 문제
두 개의 물체를 렌더링하되, 하나는 MatSpecular를 (1, 1, 1, 256)로 설정(날카로운 흰색 하이라이트)하고, 다른 하나는 (1, 0.8, 0.2, 32)로 설정(부드러운 금색 하이라이트)하여 재질의 차이를 관찰해보세요.

6주차: 노멀 매핑 (Normal Mapping)
🎯 학습 목표:

폴리곤(Polygon) 수를 늘리지 않고 표면에 복잡한 요철 디테일을 추가하는 원리를 배웁니다.

탄젠트 공간(Tangent Space)의 개념을 이해하고 셰이더에 적용합니다.

핵심 이론
디테일의 착시
조명 계산의 핵심은 법선 벡터(Normal)입니다. 만약 우리가 픽셀마다 법선 벡터의 방향을 마음대로 조절할 수 있다면, 평평한 표면도 울퉁불퉁하게 보이도록 '속임수'를 쓸 수 있습니다. 노멀 맵은 바로 이 법선 벡터의 방향 정보(XYZ)를 RGB 색상으로 저장한 특별한 텍스처입니다.

탄젠트 공간 (Tangent Space)
노멀 맵에 저장된 법선 정보는 '평평한 표면'을 기준으로 만들어집니다. 이 정보를 둥근 3D 모델 표면에 올바르게 적용하려면, 각 정점마다의 로컬 좌표계가 필요합니다. 이것이 바로 탄젠트 공간입니다.

N (Normal): 기존의 정점 법선 방향 (표면에서 위쪽)

T (Tangent): 텍스처의 U좌표가 증가하는 방향 (표면의 가로 방향)

B (Bitangent): N과 T에 모두 수직인 방향 (표면의 세로 방향)

우리는 정점 셰이더에서 이 T, B, N 벡터를 이용해 월드 공간으로 변환하는 행렬(TBN 행렬)을 만들고, 픽셀 셰이더에서 노멀 맵의 값을 이 행렬로 변환하여 최종 법선 벡터를 구합니다.

HLSL 실습 코드: 노멀 매핑 적용
// 새로운 텍스처: 노멀 맵
Texture2D NormalMap;

// VS_INPUT: 탄젠트 정보 추가
struct VS_INPUT
{
    float4 Pos : POSITION;
    float3 Normal : NORMAL;
    float2 Tex : TEXCOORD;
    float3 Tangent : TANGENT; // 탄젠트 벡터
};

// PS_INPUT: TBN 행렬을 전달하기 위한 공간
struct PS_INPUT
{
    // ... 기존 멤버들 ...
    float3x3 TBN : TEXCOORD2; // Tangent-to-World 변환 행렬
};

PS_INPUT VS(VS_INPUT input)
{
    PS_INPUT output = (PS_INPUT)0;
    // ... Pos, WorldPos 변환 ...

    // N, T를 월드 공간으로 변환
    float3 worldNormal = normalize(mul(input.Normal, (float3x3)World));
    float3 worldTangent = normalize(mul(input.Tangent, (float3x3)World));
    // B는 N과 T의 외적(cross product)으로 계산
    float3 worldBitangent = cross(worldNormal, worldTangent);

    // TBN 행렬 생성 및 픽셀 셰이더로 전달
    output.TBN = float3x3(worldTangent, worldBitangent, worldNormal);
    
    // ... UV, Pos 등 나머지 값 전달 ...
    return output;
}

float4 PS(PS_INPUT input) : SV_Target
{
    // 노멀 맵에서 법선 정보 샘플링
    float3 tangentNormal = NormalMap.Sample(ObjSampler, input.Tex).xyz;
    // 0~1 범위를 -1~1 범위로 변환
    tangentNormal = normalize(tangentNormal * 2.0f - 1.0f);

    // 샘플링된 탄젠트 공간 법선을 TBN 행렬을 이용해 월드 공간으로 변환
    float3 finalNormal = normalize(mul(tangentNormal, input.TBN));

    // --- 이후의 모든 조명 계산은 'input.Normal' 대신 'finalNormal'을 사용 ---
    // ... 블린-퐁 조명 계산 ...
}

✅ 6주차 연습 문제
픽셀 셰이더에서 조명 계산 시 finalNormal 대신 원래의 input.Normal을 사용하여 결과를 비교해보세요. 노멀 매핑 효과가 어떻게 사라지는지 확인합니다.

7주차: 그림자 매핑 (Shadow Mapping)
🎯 학습 목표:

장면에 깊이와 사실감을 더하는 동적 그림자를 구현하는 원리를 학습합니다.

2단계(Two-Pass) 렌더링 기법을 이해합니다.

핵심 이론: 빛의 시점에서 렌더링하기
그림자 매핑은 간단한 아이디어에서 출발합니다: "어떤 한 점이 빛의 입장에서 보이지 않는다면, 그 점은 그림자 속에 있다."

1단계: 깊이 맵(Depth Map) 생성

카메라를 광원의 위치와 방향으로 옮깁니다.

이 '광원 카메라'의 시점에서 장면을 렌더링합니다.

이때, 색상 정보 대신 각 픽셀이 광원으로부터 얼마나 떨어져 있는지(깊이 값)를 텍스처에 저장합니다. 이 텍스처를 깊이 맵 또는 그림자 맵이라고 합니다.

2단계: 최종 장면 렌더링

원래의 카메라 시점으로 돌아와 장면을 렌더링합니다.

픽셀 셰이더에서 렌더링 중인 각 픽셀에 대해 다음을 계산합니다.
a. 이 픽셀의 월드 좌표를 '광원 카메라'의 시점으로 변환합니다.
b. 이 변환된 좌표를 이용해 1단계에서 만든 깊이 맵에서 깊이 값(A)을 샘플링합니다.
c. 이 픽셀의 실제 광원까지의 거리(B)를 계산합니다.
d. 만약 B > A 라면, 이 픽셀은 광원과 깊이 맵에 기록된 물체 사이에 가려져 있다는 의미이므로 그림자입니다. 그렇지 않으면 빛을 받습니다.

품질 개선:

그림자 여드름 (Shadow Acne): 정밀도 문제로 물체가 스스로 그림자를 만드는 현상. 깊이 값을 비교할 때 약간의 오차(Bias)를 주어 해결합니다.

계단 현상 (Aliasing): 그림자 경계가 톱니처럼 보이는 현상. PCF(Percentage-Closer Filtering) 기법을 사용하여 깊이 맵을 여러 번 샘플링하고 결과를 평균내어 경계를 부드럽게 만듭니다.

HLSL 실습 코드: 그림자 확인
// 추가 상수 버퍼: 광원의 View-Projection 행렬
cbuffer CBufferLight
{
    float4x4 LightViewProj;
}

// 텍스처와 샘플러
Texture2D ShadowMap;
SamplerComparisonState ShadowSampler; // PCF를 위한 특별한 샘플러

// VS_OUTPUT: 광원 시점에서의 위치 추가
struct PS_INPUT {
    // ...
    float4 LightViewPos : TEXCOORD3;
};

PS_INPUT VS(VS_INPUT input) {
    PS_INPUT output;
    // ...
    // 광원 시점에서의 좌표 계산
    output.LightViewPos = mul(input.Pos, LightViewProj);
    return output;
}

float4 PS(PS_INPUT input) : SV_Target {
    // ... 조명 계산 ...

    // 그림자 계산
    float shadow = 1.0f; // 1.0 = 빛 받음, 0.0 = 그림자

    // SampleCmp: 하드웨어 가속으로 깊이 비교와 필터링(PCF)을 동시에 수행
    // 4x4 영역을 샘플링하여 부드러운 그림자 생성
    float2 texelSize = 1.0f / ShadowMapSize; // ShadowMapSize는 텍스처 크기
    for(int x = -1; x <= 1; ++x) {
        for(int y = -1; y <= 1; ++y) {
            shadow -= (1.0f/9.0f) * (1.0f - ShadowMap.SampleCmp(
                ShadowSampler, 
                input.LightViewPos.xy / input.LightViewPos.w + float2(x, y) * texelSize, 
                input.LightViewPos.z / input.LightViewPos.w - 0.001f // Depth Bias
            ));
        }
    }

    // 최종 색상에 그림자 적용 (그림자 영역은 난반사광과 정반사광을 제거)
    float3 finalColor = (ambient * textureColor.rgb) + shadow * (diffuse * textureColor.rgb + specular);
    return float4(finalColor, 1.0f);
}

8주차: 반사 및 환경 매핑
🎯 학습 목표:

큐브맵(Cubemap)을 이용해 하늘과 같은 원거리 배경(스카이박스)을 구현합니다.

주변 환경을 물체 표면에 반사시켜 금속이나 거울 같은 재질을 표현합니다.

핵심 이론
큐브맵 (Cubemap)과 스카이박스 (Skybox)
하늘, 우주, 먼 산과 같은 원거리 배경은 거대한 정육면체 안쪽에 6장의 텍스처를 붙여 표현할 수 있습니다. 이를 스카이박스라고 하며, 이 6장의 텍스처 묶음을 큐브맵이라고 합니다. 큐브맵은 2D UV 좌표가 아닌 3D 방향 벡터로 색상을 샘플링합니다.

환경 매핑 (Environment Mapping)
거울 같은 표면의 반사 색상은 '시선이 표면에서 반사되어 나아가는 방향에 있는景色의 색상'입니다.

카메라에서 표면으로 향하는 입사 벡터(I)를 구합니다.

표면의 법선 벡터(N)를 이용해 반사 벡터(R = reflect(I, N))를 계산합니다.

이 반사 벡터(R)를 방향으로 사용하여 스카이박스의 큐브맵을 샘플링합니다.

샘플링한 색상이 바로 그 픽셀의 반사 색상이 됩니다.

HLSL 실습 코드: 환경 반사
// 새로운 텍스처: 큐브맵
TextureCube SkyboxTexture;

float4 PS(PS_INPUT input) : SV_Target {
    // ... 이전 단계의 조명 및 그림자 계산 ...

    // 반사 계산
    float3 viewDir = normalize(CameraPos.xyz - input.WorldPos);
    // 입사 벡터는 viewDir의 반대
    float3 incident = -viewDir;
    float3 reflectionVector = reflect(incident, finalNormal);

    // 반사 벡터로 큐브맵을 샘플링하여 반사 색상 획득
    float4 reflectionColor = SkyboxTexture.Sample(ObjSampler, reflectionVector);

    // lerp 함수를 이용해 조명 색상과 반사 색상을 혼합
    // MatSpecular.a (알파값)를 반사율로 사용
    float reflectivity = MatSpecular.a;
    finalColor = lerp(finalColor, reflectionColor.rgb, reflectivity);
    
    return float4(finalColor, 1.0f);
}
8주차 연습 문제
reflect 함수 대신 HLSL의 내장 함수인 refract를 사용하여 굴절 효과를 시뮬레이션 해보세요. 물체가 유리처럼 보이게 됩니다.

9주차: 미니 프로젝트 #2
🎯 학습 목표:

Part 2에서 배운 중급 셰이딩 기법(고급 조명, 노멀맵, 그림자, 반사)을 하나의 장면에 모두 통합합니다.

프로젝트 가이드
요구 사항:

장면 구성: 바닥 평면과 그 위에 놓인 중앙 모델(캐릭터, 로봇 등)로 장면을 구성합니다.

스카이박스: 장면 전체를 둘러싸는 스카이박스를 렌더링합니다.

재질: 중앙 모델과 바닥 평면이 서로 다른 재질 속성을 갖도록 설정합니다. (예: 모델의 갑옷은 반사율이 높은 금속, 바닥은 무광의 흙)

노멀 매핑: 중앙 모델과 바닥 평면 모두 노멀 맵을 사용하여 표면 디테일을 표현합니다.

동적 그림자: 방향성 광원을 설치하고, 중앙 모델이 바닥 평면에 그림자를 드리우도록 구현합니다. PCF를 적용하여 부드러운 그림자 경계를 만듭니다.

반사: 중앙 모델의 금속 부분은 주변 스카이박스를 반사하도록 셰이더를 작성합니다.

기대 결과:
노멀 맵으로 디테일이 살아있고, 부드러운 그림자로 깊이감이 느껴지며, 금속 재질이 주변 환경을 반사하는, 시각적으로 풍부하고 사실적인 3D 장면을 완성합니다.
