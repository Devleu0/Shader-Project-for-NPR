## HLSL/DirectX 셰이더 프로그래밍 학습자료 (Part 1)
이 문서는 셰이더 프로그래밍에 처음 입문하는 분들을 위해 그래픽스 파이프라인의 기초부터 조명, 텍스처 매핑까지의 과정을 안내합니다. 각 주차별 목표를 따라 이론을 학습하고 실습 코드를 직접 작성해보세요.

1주차: 그래픽스 파이프라인과 나의 첫 셰이더
 학습 목표:

3D 모델이 화면에 그려지는 전체 과정을 이해합니다.

가장 기본적인 정점(Vertex) 셰이더와 픽셀(Pixel) 셰이더를 작성합니다.

CPU에서 GPU로 데이터를 전달하는 방법(상수 버퍼)을 배웁니다.

## 핵심 이론
* 렌더링 파이프라인 (Rendering Pipeline)
3D 모델 데이터가 모니터의 2D 픽셀로 변환되는 과정을 '공장 라인'처럼 표현한 것입니다. DirectX에서는 이 파이프라인의 주요 단계를 프로그래밍할 수 있습니다.

* 입력 조립기 (Input Assembler): 정점(점) 데이터를 받아 삼각형 같은 기본 도형으로 조립합니다.

* 정점 셰이더 (Vertex Shader): (우리가 코딩할 첫 번째 영역!) 모델의 모든 정점을 3D 공간에서 2D 화면 공간으로 변환(이동, 회전, 크기 조절)합니다.

* 래스터라이저 (Rasterizer): 정점 셰이더가 만든 도형을 픽셀 단위로 쪼갭니다. 이 도형이 화면의 어떤 픽셀을 덮을지 결정합니다.

* 픽셀 셰이더 (Pixel Shader): (우리가 코딩할 두 번째 영역!) 래스터라이저가 생성한 각 픽셀의 최종 색상을 계산합니다.

* 출력 병합기 (Output Merger): 픽셀 셰이더가 계산한 색상을 화면에 최종적으로 출력합니다.

* HLSL (High-Level Shading Language)
GPU에서 실행되는 셰이더 프로그램을 작성하기 위한 C언어와 유사한 문법을 가진 언어입니다.

* 상수 버퍼 (Constant Buffer)
CPU(우리의 C++ 프로그램)에서 셰이더(GPU)로 데이터를 전달하는 통로입니다. 예를 들어, 물체의 위치나 카메라의 위치 같은 정보를 전달할 때 사용합니다.

## HLSL 실습 코드: 단색으로 모델 칠하기
이 셰이더는 모델을 월드-뷰-프로젝션 행렬을 이용해 변환하고, 모든 픽셀을 지정된 단색으로 칠합니다.
```hlsl
// Constant Buffer: CPU에서 GPU로 데이터를 보내는 통로
cbuffer CBufferPerObject
{
    float4x4 WVP; // World * View * Projection 행렬
    float4 OutputColor; // 모델에 칠할 색상
}

// Vertex Shader의 입력 데이터 구조
struct VS_INPUT
{
    float4 Pos : POSITION; // 정점의 위치
};

// Vertex Shader의 출력 (Pixel Shader의 입력) 데이터 구조
struct PS_INPUT
{
    float4 Pos : SV_POSITION; // 시스템 값: 변환된 최종 위치
};

// Vertex Shader 함수
PS_INPUT VS(VS_INPUT input)
{
    PS_INPUT output = (PS_INPUT)0;
    // 입력된 정점 위치를 WVP 행렬과 곱하여 최종 화면 위치로 변환
    output.Pos = mul(input.Pos, WVP);
    return output;
}

// Pixel Shader 함수
float4 PS(PS_INPUT input) : SV_Target
{
    // 상수 버퍼에서 받은 색상을 그대로 반환
    return OutputColor;
}
```
주요 함수/키워드
* cbuffer: 상수 버퍼를 선언합니다.

* float4, float4x4: 4개의 float 변수를 가진 벡터, 4x4 float 행렬을 의미합니다.

* : POSITION, : SV_POSITION, : SV_Target: 시맨틱(Semantic)이라고 부르며, 이 변수가 파이프라인에서 어떤 역할을 하는지 알려주는 약속입니다.

* mul(vector, matrix): 벡터와 행렬의 곱셈을 수행하는 내장 함수입니다.

2주차: 기본 조명 모델 (퐁 조명)
🎯 학습 목표:

빛의 3가지 기본 요소를 이해하고 3D 모델에 입체감을 부여합니다.

물체 표면의 방향을 나타내는 법선 벡터(Normal Vector)의 중요성을 배웁니다.

핵심 이론
* 퐁 조명 모델 (Phong Lighting Model)
컴퓨터 그래픽스에서 가장 기본적이고 널리 쓰이는 조명 모델입니다. 현실의 빛을 3가지 요소로 단순화하여 계산합니다.

* 환경광 (Ambient): "기본 밝기"입니다. 광원에게 직접 빛을 받지 않는 그림자 속 물체도 희미하게 보이도록 만들어 줍니다. 장면 전체에 고르게 적용되는 빛입니다.

* 난반사광 (Diffuse): "물체의 고유 색상"을 나타내는 가장 중요한 빛입니다. 빛의 방향과 물체 표면이 마주 보는 각도에 따라 밝기가 결정됩니다. 예를 들어, 빛을 정면으로 받는 표면은 가장 밝고, 비스듬히 받는 표면은 더 어둡습니다.

* 정반사광 (Specular): "반짝이는 하이라이트"입니다. 매끄러운 표면(플라스틱, 금속 등)에서 빛이 반사되어 우리 눈에 직접 들어올 때 생기는 밝은 점입니다. 시점의 위치에 따라 하이라이트의 위치가 바뀝니다.

이 모든 계산을 위해서는 **법선 벡터(Normal Vector)**가 필수적입니다. 법선 벡터는 각 표면이 어느 방향을 바라보고 있는지를 알려주는 길이 1의 벡터입니다.

HLSL 실습 코드: 퐁 조명 구현
```hlsl
// 조명과 관련된 데이터를 담을 상수 버퍼
cbuffer CBufferPerFrame
{
    float4 LightDir;      // 광원의 방향
    float4 LightColor;    // 광원의 색상
    float4 CameraPos;     // 카메라(시점)의 위치
}

// 정점 셰이더 입력: 위치, 법선
struct VS_INPUT
{
    float4 Pos : POSITION;
    float3 Normal : NORMAL;
};

// 픽셀 셰이더 입력
struct PS_INPUT
{
    float4 Pos : SV_POSITION;
    float3 Normal : NORMAL;   // 월드 공간 기준으로 변환된 법선
    float3 WorldPos : TEXCOORD0; // 월드 공간 기준의 정점 위치
};

// 정점 셰이더
PS_INPUT VS(VS_INPUT input)
{
    PS_INPUT output = (PS_INPUT)0;
    output.Pos = mul(input.Pos, WVP);
    output.WorldPos = (float3)mul(input.Pos, World); // World 행렬만 곱해 월드 위치 계산
    output.Normal = (float3)mul(input.Normal, (float3x3)World); // 법선 변환
    return output;
}

// 픽셀 셰이더
float4 PS(PS_INPUT input) : SV_Target
{
    // 1. 기본 환경광(Ambient) 계산 (여기선 광원 색의 15%로 설정)
    float3 ambient = LightColor.rgb * 0.15f;

    // 2. 난반사광(Diffuse) 계산
    // 법선 벡터와 빛의 방향 벡터를 정규화(길이 1로 만듦)
    float3 normal = normalize(input.Normal);
    float3 lightDir = normalize(-LightDir.xyz);
    // 두 벡터의 내적(dot)을 통해 빛의 세기를 구함 (0~1 사이 값)
    float diffFactor = saturate(dot(normal, lightDir));
    float3 diffuse = diffFactor * LightColor.rgb;

    // 3. 정반사광(Specular) 계산
    float3 viewDir = normalize(CameraPos.xyz - input.WorldPos);
    float3 reflectDir = reflect(-lightDir, normal); // 반사 벡터 계산
    // 반사 벡터와 시선 벡터가 얼마나 가까운지에 따라 반짝임 결정
    float specFactor = pow(saturate(dot(viewDir, reflectDir)), 32.0f); // 32는 반짝임의 날카로움(shininess)
    float3 specular = specFactor * LightColor.rgb;

    // 최종 색상 = (환경광 + 난반사광) * 물체색 + 정반사광
    // (여기서 물체색은 흰색(1,1,1)으로 가정)
    float3 finalColor = ambient + diffuse + specular;

    return float4(finalColor, 1.0f);
}
```
주요 함수/키워드
* normalize(vector): 벡터의 길이를 1로 만듭니다. 방향 계산에 필수적입니다.

* dot(vecA, vecB): 두 벡터의 내적을 구합니다. 두 벡터가 얼마나 같은 방향을 보는지(사이각)를 나타냅니다.

* saturate(value): 값을 0.0 ~ 1.0 사이로 제한합니다. 색상이나 비율 계산에 유용합니다.

* reflect(incident, normal): 입사 벡터와 법선 벡터를 이용해 반사 벡터를 계산합니다.

* pow(base, exponent): 거듭제곱을 계산합니다. Specular 계산에서 하이라이트를 좁고 선명하게 만드는 데 사용됩니다.

3주차: 텍스처 매핑 (Texture Mapping)
🎯 학습 목표:

2D 이미지(텍스처)를 3D 모델 표면에 입히는 원리를 이해합니다.

UV 좌표와 샘플러의 개념을 배웁니다.

핵심 이론
* 텍스처 (Texture)와 UV 좌표
텍스처는 3D 모델의 표면에 씌우는 2D 이미지 파일(jpg, png 등)입니다. 3D 모델의 각 정점은 이 2D 이미지의 어느 부분에 해당하는지를 나타내는 좌표를 가지는데, 이를 UV 좌표라고 합니다. UV 좌표는 보통 0.0 ~ 1.0 사이의 값을 가집니다. (U는 가로, V는 세로)

* 샘플러 (Sampler)
텍스처에서 색상 값을 어떻게 읽어올지를 정의하는 규칙입니다.

* 필터링 (Filtering): 텍스처를 확대/축소할 때 픽셀 사이의 색을 어떻게 처리할지 결정합니다. (예: Linear는 부드럽게 보간, Point는 픽셀을 그대로 보여줌)

* 어드레스 모드 (Address Mode): UV 좌표가 0.0 ~ 1.0 범위를 벗어났을 때 어떻게 처리할지 결정합니다. (예: Wrap은 반복, Clamp는 가장자리 색으로 유지)

HLSL 실습 코드: 텍스처를 이용한 조명
이제 2주차 코드에서 물체의 고유 색상을 단색이 아닌 텍스처에서 읽어온 색으로 바꿉니다.
```hlsl
// ... (이전 주의 상수 버퍼들은 동일) ...

// 텍스처와 샘플러 객체 선언
Texture2D ObjTexture;
SamplerState ObjSampler;

// 정점 셰이더 입력: 위치, 법선, 텍스처 좌표 추가
struct VS_INPUT
{
    float4 Pos : POSITION;
    float3 Normal : NORMAL;
    float2 Tex : TEXCOORD; // UV 좌표
};

// 픽셀 셰이더 입력: 텍스처 좌표 추가
struct PS_INPUT
{
    float4 Pos : SV_POSITION;
    float3 Normal : NORMAL;
    float3 WorldPos : TEXCOORD0;
    float2 Tex : TEXCOORD1; // 정점 셰이더에서 보간된 UV 좌표
};

// 정점 셰이더
PS_INPUT VS(VS_INPUT input)
{
    PS_INPUT output = (PS_INPUT)0;
    // ... (Pos, WorldPos, Normal 변환은 2주차와 동일) ...
    output.Tex = input.Tex; // UV 좌표를 그대로 픽셀 셰이더로 전달
    return output;
}

// 픽셀 셰이더
float4 PS(PS_INPUT input) : SV_Target
{
    // ... (ambient, diffFactor, specular 계산은 2주차와 동일) ...

    // 텍스처에서 현재 픽셀의 색상을 샘플링
    float4 textureColor = ObjTexture.Sample(ObjSampler, input.Tex);

    // 난반사광 계산 시 텍스처 색상을 곱해줌
    float3 diffuse = diffFactor * LightColor.rgb * textureColor.rgb;
    
    // 최종 색상 = (환경광 * 텍스처 색) + 난반사광 + 정반사광
    float3 finalColor = (ambient * textureColor.rgb) + diffuse + specular;

    return float4(finalColor, textureColor.a); // 텍스처의 알파값 사용
}
```
