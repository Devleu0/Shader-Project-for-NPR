# HLSL/DirectX 문서 실습 환경과 공통 규약

이 폴더(`Shader Learning`)와 `Directx11` 폴더의 HLSL 코드는 **셰이더 부분만** 담고 있습니다. 화면에 결과를 보려면 C++ 호스트 프로그램(Direct3D 11 초기화, 정점/상수 버퍼·텍스처 생성, 셰이더 바인딩)이 필요합니다. 아래 순서로 따라 하세요.

## 1. 준비물
| 항목 | 내용 |
|---|---|
| OS / 도구 | Windows 10/11, Visual Studio 2022 ("C++를 사용한 데스크톱 개발" 워크로드, Windows SDK 포함) |
| API | Direct3D 11 (Feature Level 11_0 이상 GPU. 테셀레이션/컴퓨트 예제는 11_0 필요) |
| 디버깅 | RenderDoc 또는 Visual Studio 그래픽스 진단 (렌더 결과가 안 나올 때 가장 먼저 쓸 도구) |

## 2. 호스트 코드는 어디서 얻나
| 목적 | 자료 |
|---|---|
| 창 + 장치 + 삼각형 (가장 작은 예제) | [DirectX 11 1단계](../Directx11/DirectX%2011%201단계.md) 의 전체 코드 |
| 상수 버퍼, 텍스처, 모델, 카메라까지 | Microsoft **DirectX Tool Kit (DirectXTK) 튜토리얼**, Rastertek DX11 튜토리얼, Frank Luna 책 예제 |
| 그 외 (그림자 맵, 렌더 타겟, 컴퓨트 등) | Microsoft DirectX-Graphics-Samples / Direct3D 11 샘플 |

각 주차 문서는 "어떤 셰이더 코드를 쓰는가"를 설명하고, 호스트가 해야 할 일(버퍼 생성, 바인딩)을 `호스트에서 할 일` 로 표시합니다.

## 3. 공통 규약 (모든 예제가 따름)
1. **행렬 곱 순서**: 예제는 `mul(vector, matrix)` (행 벡터 × 행렬) 형태입니다. DirectXMath/SimpleMath 는 행 우선(row-major) 행렬이고 HLSL 상수 버퍼의 기본 패킹은 열 우선(column-major) 이므로, **C++ 에서 상수 버퍼에 올리기 전에 반드시 전치(Transpose)** 해야 합니다.
   ```cpp
   cb.WVP = XMMatrixTranspose(world * view * proj);   // 전치해서 업로드
   ```
   (전치하지 않으려면 HLSL 쪽에 `row_major float4x4 WVP;` 로 선언하고 같은 `mul(v, M)` 을 씁니다.)
2. **상수 버퍼 크기**: 상수 버퍼의 `ByteWidth` 는 **16바이트의 배수**여야 하고, 멤버는 16바이트 경계를 넘지 않게 배치됩니다 (`float3` 뒤에 `float` 하나는 같은 16바이트 칸에 들어감, `float` 다음 `float3` 는 새 칸). 그래서 예제는 `float4` 위주로 선언합니다.
3. **좌표계**: 왼손 좌표계, 시계 방향 감김(winding)이 앞면 (D3D11 기본 래스터라이저 상태 `FrontCounterClockwise = FALSE`).
4. **정점 입력**: 입력 레이아웃에서 `R32G32B32_FLOAT` 위치를 `float4 Pos : POSITION` 으로 받으면 `w` 는 자동으로 1 이 됩니다.
5. **레지스터**: 예제는 가독성을 위해 `register(...)` 를 생략하기도 합니다. 생략하면 컴파일러가 선언 순서대로 b0, t0, s0 … 을 배정하므로, 호스트에서 `VSSetConstantBuffers(0, …)`, `PSSetShaderResources(0, …)` 등의 슬롯 번호를 **셰이더의 선언 순서**와 맞추세요. 확실히 하려면 `: register(b0)` 처럼 명시합니다.
6. **색 공간**: 텍스처가 sRGB 인 경우 `DXGI_FORMAT_*_SRGB` 로 SRV/RTV 를 만들어야 선형 공간에서 계산되고 출력 시 자동 감마 보정이 됩니다 (PBR 문서에서 중요).

## 4. 셰이더 문법만 먼저 확인하기 (호스트 없이)
Visual Studio 의 "개발자 명령 프롬프트" 에서 (Windows SDK 에 `fxc.exe` 포함):
```
fxc /nologo /T vs_5_0 /E VS shader.hlsl
fxc /nologo /T ps_5_0 /E PS shader.hlsl
```
문서의 코드는 발췌 조각이 많으므로, 조각 앞에 해당 주차에서 선언한 `cbuffer`/`struct` 를 직접 붙여야 컴파일됩니다. 주차별로 "완성형"으로 바로 컴파일되는 코드는 문서에서 **(완성형)** 으로 표시합니다.

> **검증 상태**: 이 문서들의 코드는 작성자가 Windows/Visual Studio 에서 직접 컴파일해 확인하지 않았습니다. 코드를 수정할 때는 위 규약과 수학적 일관성(행렬 순서, 정규화, 좌표 공간)을 기준으로 검토했습니다. 컴파일 오류를 발견하면 이슈로 남겨 주세요.
